# Frontend

SmartMoney uses React 18 with Vite for the frontend application.

## Main Pages

- Dashboard
- Expenses
- Analytics
- Savings
- Investments
- Recurring Expenses
- Budget
- Settings
- Profile
- Support
- Login and Registration
- Onboarding

## Frontend Structure

- `src/pages` contains application pages.
- `src/components` contains reusable UI and feature components.
- `src/services` communicates with backend APIs.
- `src/hooks` contains reusable financial data hooks.
- `src/context` manages authentication and theme state.
- `src/utils` contains formatting, analytics, reporting, and export helpers.
- `src/styles` contains global, responsive, page, and dashboard styling.

## Visualization

SmartMoney uses Recharts, Chart.js, and React Chart.js 2 for financial visualizations.

## Reports

Financial data can be exported through PDF and Excel report utilities.
